应用采用 Vue3 单页应用架构：`main.js` 通过 `createApp` 挂载根组件 `App.vue`（仅包含 `<router-view />`），并注册 Pinia 与 vue-router；路由在 `router/index.js` 中以懒加载方式定义 `/`、`/poi/:id`、`/search`、`/panorama` 四个页面。

- 状态管理：`stores/` 下使用 Pinia Composition API 风格 store（`poi.js` 维护 POI 数据与分类、`map.js` 维护地图配置与像素坐标换算、`audio.js` 管理音频播放），由组件直接通过 `useXxxStore()` 访问。
- 可复用逻辑：`composables/` 封装跨组件复用的副作用逻辑，如 `useMap.js` 封装 Leaflet 地图初始化（自定义 CRS.Simple 像素坐标系、瓦片 y-flip 适配、双指缩放阈值）、`useGeolocation.js`、`useAudio.js`。
- 组件分层：`components/common/` 为通用 UI（SearchBar、AudioPlayer、PoiBottomSheet、VisitorCounter）；`components/map/` 聚焦地图交互（LeafletMap 负责地图实例与标记渲染、MapControls 控制缩放、CategoryTabs 分类切换、PoiMarker/PoiEditDialog 处理标记与编辑）；`components/detail/` 承载详情页子模块（ActionButtons、PoiInfo、VREntry、VideoPlayer）。
- 数据层：`data/mock.js` 提供静态 POI 数据，当前无后端集成。
- 样式：`styles/variables.css` 集中 CSS 变量，`App.vue` 内定义全局重置与 Leaflet 标记样式，各组件使用 scoped 样式。
依赖方向自上而下：views → components → composables/stores/data，store 不反向依赖组件。
