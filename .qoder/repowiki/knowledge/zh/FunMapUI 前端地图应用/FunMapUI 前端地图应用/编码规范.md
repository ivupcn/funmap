- Pinia store 统一使用 Composition API 风格的 `defineStore(name, () => {...})` 写法，并通过 `ref`/`computed` 暴露响应式状态与函数。
- 组件间共享的副作用逻辑抽取到 `composables/use*.js`，以函数形式接收 ref 参数并在内部管理生命周期钩子。
- 路由组件采用 vue-router 的懒加载语法 `() => import('@/views/xxx.vue')`，避免首屏体积过大。
- 地图相关坐标统一在百分比与像素之间转换，通过 `mapStore.percentToLatLng` / `pixelToPercent` 进行换算，组件侧只持有百分比坐标。
- Leaflet 地图实例的生命周期（创建、销毁）集中在 `useMap` composable 中，通过 `onMounted`/`onUnmounted` 自动管理，组件仅消费返回的 `map` ref。
- 样式使用 CSS 变量（如 `--spacing-*`、`--color-*`、`--z-*`）集中定义于 `styles/variables.css`，组件内通过 `var(...)` 引用以保持主题一致性。
